excel-automation 스킬 사용 실습 프롬프트

먼저 `practice-samples`로 3장 실습 파일을 작업 폴더에 복사한다.
원본 파일은 `3장-엑셀실습` 폴더에 들어간다.

실습 1: 데이터 정리
실습1_고객관리_원본.xlsx를 정리해줘.
전화번호와 가입일 형식을 통일하고 중복은 지워줘.
이름과 연락처가 같은데 다른 값이 있는 행은 지우지 말고 따로 보여줘.
이메일 오타나 이상한 금액도 고치지 말고 표시만 해줘.
뭐가 바뀌었는지 변경 리포트도 같이 만들어줘.

확인할 점
- 원본 파일은 그대로이고 결과는 새 파일로 저장되었는가
- 정리 후 행 수와 지운 중복 행이 변경 리포트에 적혀 있는가
- 전화번호 오류 2건, 이메일 오타 2건, 모호한 날짜 1건, 극단값 1건이 '확인 필요'로 남아 있는가

실습 2: 분석과 시각화
실습2_쇼핑몰매출_원본.xlsx를 분석해줘.
월별 매출 추이와 카테고리별 매출 비교를 차트로 보여주고,
가장 많이 팔린 상품과 핵심 인사이트 3~5개를 정리해줘.

확인할 점
- 차트를 클릭하면 시트의 숫자가 보이는가(그림이 아니라 엑셀 차트인가)
- 인사이트의 숫자가 표에 있는 숫자와 같은가

실습 3: 멀티탭 취합
실습3_멀티채널판매_원본.xlsx의 채널 탭들을 상품코드 기준으로 하나의 통합관리 시트로 취합해줘.
채널마다 등록된 상품이 다르니 일부 채널에만 있는 상품도 빠지지 않게 해줘.
원본 탭은 그대로 두고 채널별 판매량을 한눈에 비교할 수 있게 만들어줘.

확인할 점
- 원본 탭 7개가 그대로 남아 있는가
- 통합관리 시트의 상품 수가 모든 탭 상품코드의 합집합과 같은가
- 쿠팡 탭의 판매량을 바꾸면 통합관리 시트의 값도 바뀌는가(수식 연결)

강사용 정답표: `3장-엑셀실습/강사용/answer_key.json`
