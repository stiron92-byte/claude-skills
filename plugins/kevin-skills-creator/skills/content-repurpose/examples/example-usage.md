# 사용 예시 — 유튜브 대본 → SEO 블로그·X 스레드·Instagram

원본: `examples/source-1인개발자.md`(1인 개발자 수익 대본).
요청: "이 유튜브 대본을 블로그, X 스레드, 인스타 캡션으로 바꿔줘."

## 흐름

1. 원본을 `<W>/source.md`로 저장한다.
2. 브리프(`<W>/brief.json`): 핵심 메시지 3개(SaaS 구독 모델 / 블로그·강의로 포트폴리오와 수익 / 컨설팅은 운영 경험 이후), 단서(한 번에 시작하지 말 것, 단계적 확장), 숫자(2만원, 200명, 50만원, 150만원, 20만원, 10시간, 400·200·300·900·700만원).
3. 플랫폼은 요청에 있으므로 묻지 않는다: `seo_blog`, `x_thread`, `instagram`.
4. 세 플랫폼 파일만 읽고 쓴다.
5. 검증:

   ```bash
   python ${CLAUDE_SKILL_DIR}/scripts/check_repurpose.py <W>/repurposed.md --source <W>/source.md --platforms seo_blog,x_thread,instagram --brief <W>/brief.json
   ```

v1.6.1 예시에는 원본에 없는 내용이 섞여 있었다. 이 예시는 검증을 통과하도록 고쳤다(저장소 테스트 `tests/check_repurpose_verify.py`가 이 파일을 검사한다).

- "앱스토어 수수료(30%)", "수수료 0%"
- "퇴근 후 2시간, 주말 4시간이면 충분"
- 원본에 없는 계산식 "시간당 20만원 × 주 10시간 = 월 300만원"

아래가 결과 파일의 본문이다. 플랫폼마다 `## 섹션` 하나다.

## SEO 블로그 포스트

제목: 1인 개발자 수익화 3단계 — SaaS, 블로그·강의, 컨설팅
메타 디스크립션: 회사를 그만두고 3년 동안 SaaS, 기술 블로그·유료 강의, 컨설팅을 차례로 더해 월 900만 원 수익 구조를 만든 1인 개발자의 방법을 정리했습니다.
키워드: 1인 개발자 수익, SaaS 구독 모델, 기술 블로그 수익화, 개발자 컨설팅

회사를 나와 혼자 개발하며 먹고살 수 있을까요? 이 글의 주인공도 처음엔 막막했습니다. 3년 동안 시행착오를 거치며 수익원을 하나씩 더했고, 지금은 세 갈래의 수익 구조가 있습니다.

### 1. 웹 기반 SaaS — 구독 모델로 시작

앱보다 웹 기반 SaaS가 1인 개발자에게 효율적입니다. 앱스토어 수수료가 없고, 업데이트가 자유롭고, 구독 모델을 적용하기 쉽기 때문입니다. 개발자를 위한 코드 리뷰 자동화 도구를 월 구독료 2만 원으로 시작해 지금은 유료 사용자가 200명 정도입니다.

### 2. 기술 블로그와 유료 강의

개발하며 배운 것을 블로그에 정리하면 포트폴리오가 되고 마케팅이 됩니다. 트래픽이 쌓이면 유료 강의나 전자책으로 이어집니다. 블로그 광고 수익은 월 50만 원, 유료 강의는 월 150만 원 정도입니다.

### 3. 프리랜서 컨설팅 — 운영 경험이 생긴 뒤에

SaaS를 운영한 경험이 생기자 스타트업의 컨설팅 요청이 들어왔습니다. 시간당 20만 원 정도를 받고, 주 10시간 정도를 할애해 월 300만 원 이상의 추가 수입이 됩니다.

### 수익 구조 요약

| 수익원 | 월 수익 |
|--------|---------|
| SaaS | 400만 원 |
| 블로그·강의 | 200만 원 |
| 컨설팅 | 300만 원 |
| 합계 | 약 900만 원 |
| 실수령(서버비·도구 비용 차감) | 약 700만 원 |

### 핵심: 한 번에 다 시작하지 않는다

SaaS부터 시작해 1년 뒤 블로그를, 2년 뒤 컨설팅을 더했습니다. 단계적으로 확장하는 것이 핵심입니다.

다음 글에서는 SaaS 아이디어를 찾는 구체적인 방법을 이어서 소개합니다.

## X 스레드

1/6 회사 그만두고 혼자 개발한 지 3년. 월 900만 원이 어디서 나오는지 숫자로 풀어 봅니다. 🧵

2/6 첫째, SaaS. 앱 말고 웹 구독. 수수료 없고 업데이트 자유. 월 2만 원짜리 코드 리뷰 도구에 유료 사용자 200명, 월 400만 원.

3/6 둘째, 기술 블로그와 유료 강의. 배운 걸 기록하면 포트폴리오이자 마케팅. 블로그 광고 월 50만 원, 강의 월 150만 원.

4/6 셋째, 컨설팅. SaaS 운영 경험이 생기니 스타트업에서 연락이 왔어요. 시간당 20만 원, 주 10시간 정도로 월 300만 원 이상.

5/6 합치면 월 900만 원, 서버비·도구 비용 빼면 실수령은 약 700만 원.

6/6 제일 중요한 건 순서. SaaS → 1년 뒤 블로그 → 2년 뒤 컨설팅. 다음엔 SaaS 아이디어 찾는 법을 정리할게요. 도움이 됐다면 리포스트!
