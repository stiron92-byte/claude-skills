# content-repurpose

> 원본 콘텐츠를 플랫폼별 게시글로 바꾸고, 콘텐츠 목록을 감사·갭 분석한다. 글자 수·형식·숫자 출처는 스크립트로 검사한다.
> 플러그인: `kevin-skills-creator` · 책 8장

## 하는 일

- **변환:** 원본을 끝까지 읽고 핵심 메시지·숫자·단서를 브리프(`brief.json`)로 정리한 뒤, 선택한 플랫폼의 스펙 파일(`references/platforms/<id>.md`)만 읽고 쓴다. 플랫폼은 14종이다.
  - `count_chars.py`가 플랫폼별 글자 수를 센다. X는 한글·이모지를 2로 세는 가중치를 쓴다. 해시태그 수와 트윗 수도 센다.
  - `check_repurpose.py`가 다음을 잡아낸다: 한도 초과, 자리표시·작성 메모·코드 블록·안내문, 원본에 없는 숫자, 빠진 플랫폼, 핵심 메시지 누락.
- **감사:** `content_inventory.py`가 목록의 수치를 정확히 센다. 카테고리 분포와 편중, 오늘 기준 경과 개월, 시의성 있는 제목, 중복 후보다. Claude는 이 수치로 해석과 액션 플랜을 쓴다.
- **갭 분석:** 경쟁 목록과 비교해 경쟁에만 있는 카테고리·형식, 겹치는 단어를 센다. 목록이 일부만 주어졌으면 그 사실을 표시한다.

## 데모

| 이렇게 요청하면 | 이런 결과가 나온다 |
|-----------------|--------------------|
| "이 유튜브 대본을 블로그, X 스레드, 인스타로 바꿔줘" | 세 섹션짜리 결과 파일. 트윗마다 가중치 280 이내, 해시태그 20~30개, 원본 숫자만 사용 |
| "이 강의 원고를 링크드인 글로" | 첫 3줄 훅과 1,300자 이내 본문, 질문형 마무리, 해시태그 3~5개 |
| (책 실습 8-1) 블로그 목록 10개 + "부족한 주제 파악" | AI 도구 50% 편중, 마지막 발행 후 18개월, 업데이트할 글 3개, 1주·1개월·3개월 액션 플랜 |
| (책 실습 8-2) 내 목록 + 경쟁 목록 | 실전 활용·자동화·실습형 갭, 일부 목록 기준이라는 표시, 4주 로드맵 |

실습 샘플은 `practice-samples` 스킬의 `repurpose-source` 세트(원본 대본)와 `repurpose-answer-key` 세트(정답표)다.

## 커스터마이즈 포인트

플러그인 설치 폴더를 고치지 말고 오버라이드 폴더에 파일을 둔다. 규약은 `references/_shared/overrides.md`에 있다.

- 팀 공용: `<작업 폴더>/.claude/claude-skills/content-repurpose/`
- 개인 기본값: `~/.claude/claude-skills/content-repurpose/`

| 수준 | 대상 | 파일(스킬 폴더 기준 상대 경로) | 형식 | 예시 |
|:---:|------|-------------------------------|------|------|
| L0 | 기본 플랫폼 묶음 | `settings.yaml` → `default_platforms` | 쉼표로 구분한 플랫폼 id | `default_platforms: naver_blog,instagram,threads` |
| L0 | 기본 톤 | `settings.yaml` → `tone` | 문자열 | `tone: 친근하지만 전문적` |
| L0 | 기본 언어 | `settings.yaml` → `language` | ko·en 등 | `language: ko` |
| L1 | 브랜드 보이스 | `references/brand-voice.md` | 마크다운 | 말투, 자주 쓰는 표현, 피할 표현, 좋은 예 2개 |
| L1 | 금칙어·해시태그 정책 | `references/banned-words.md` | 마크다운 | 경쟁사 이름, 과장 표현, 고정 해시태그 3개 |
| L2 | 사내·추가 채널 스펙 | `references/platforms/<새 id>.md` | 기존 플랫폼 파일과 같은 구조 | 사내 뉴스레터, 블라인드 채널 공지 |

사내 채널을 더한 경우 검증기는 공통 항목만 검사한다: 자리표시, 작성 메모, 코드 블록, 안내문, 숫자 출처. 한도는 스펙 파일을 보고 Claude가 지킨다.

다음 보호 규칙은 오버라이드로 바뀌지 않는다.

- 원본 덮어쓰기 금지
- 비밀 정보 파일 기록 금지
- 외부 전송·게시 전 확인(이 스킬은 게시하지 않고 글만 만든다)
- 원본에 없는 숫자·성과 지어내기 금지
- 투자 권유 금지
