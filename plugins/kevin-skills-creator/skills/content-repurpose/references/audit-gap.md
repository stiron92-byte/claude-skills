# 감사(audit)·갭 분석(gap)

두 모드 모두 숫자는 `scripts/content_inventory.py`가 세고, Claude는 해석과 제안을 쓴다.
목록에 없는 성과 데이터(조회수, 검색량, 트래픽)는 만들지 않는다. 필요하면 "데이터가 있으면 이렇게 판단한다"로 쓴다.

## 1. 입력 준비

사용자가 붙여 넣은 목록을 `<W>/list.txt`로 저장하고 실행한다. 경쟁 목록이 있으면 `<W>/competitor.txt`.

```bash
python ${CLAUDE_SKILL_DIR}/scripts/content_inventory.py <W>/list.txt [--compare <W>/competitor.txt] [--stale-months 6]
```

- 기준일은 오늘이다(`--today`로 바꿀 수 있다). 경과 개월은 오늘 기준이므로, 오래된 목록이면 "마지막 발행 후 18개월"처럼 발행 공백 자체가 핵심 발견일 수 있다.
- `partial=yes`(목록에 "(생략)", "…")면 리포트 첫머리에 "일부 목록 기준 분석"이라고 밝힌다.

## 2. 감사 리포트 구성

| 절 | 내용 | 근거 |
|----|------|------|
| 요약 | 총 개수, 핵심 발견 3가지 | 스크립트 수치 |
| 주제 분포 | 카테고리·개수·비율·상태(과잉/적정/부족) | `categories`, 편중 기준 40% |
| 시의성 | 경과 개월, 업데이트 필요 항목(버전·연도·리뷰·예측 제목) | `stale`, `time_sensitive` |
| 형식 분포 | 비교·리뷰·사용법·튜토리얼·전망 등 | `format_hints` |
| 중복·통합 | 핵심 단어를 공유하는 묶음 + 통합 제안 | `overlap_groups`(단어로 안 묶이는 관련 글은 판단으로 추가하되 그렇다고 밝힌다) |
| 액션 플랜 | 1주 / 1개월 / 3개월, 대상 콘텐츠와 기대 효과 | 위 발견에서만 도출 |

운영 채널이 여럿이면(예: 블로그·유튜브) 채널별 재활용 기회를 액션 플랜에 넣는다. 이 스킬의 변환 모드로 바로 이어질 수 있다.

## 3. 갭 분석 리포트 구성

| 절 | 내용 |
|----|------|
| 요약 | 가장 큰 갭 3가지, 바로 할 수 있는 기회, 분석 범위(일부 목록이면 그 사실) |
| 주제 갭 | 경쟁에만 있는 주제·카테고리(`only_in_other_categories`, `other_titles_without_shared_words`), 기회 크기·난이도(상/중/하는 판단이라고 밝힌다) |
| 형식 갭 | 경쟁에만 있는 형식(`only_in_other_formats`) |
| 겹치는 영역 | 공유 단어(`shared_words`) — 차별화 방향 |
| 4주 로드맵 | 주차·주제·형식·플랫폼 |

경쟁 채널을 웹에서 더 조사하면(WebSearch) 출처와 조사 시점을 적고, 검색 결과 기반이라 실제 성과와 다를 수 있다고 알린다.

## 4. 저장

리포트는 `<W>/audit-<주제>-<날짜>.md` 또는 `<W>/gap-<주제>-<날짜>.md`로 저장하고 채팅에는 요약과 경로를 준다.
