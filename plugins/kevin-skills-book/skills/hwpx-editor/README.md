# hwpx-editor

> 한글(HWPX) 양식은 그대로, 글자만 바꾸기
> 플러그인: `kevin-skills-book` · 책 2장

## 하는 일

기존 HWPX 문서나 `{{변수}}` 양식에서 텍스트만 바꿔 새 .hwpx를 만든다. 로고·결재란·표·서체·배치는 그대로 두고,
바꾸지 않은 ZIP 엔트리는 바이트 단위로 보존한다. 실행 전 plan, 실행 후 verify로 결과를 검증한다.

## 데모

| 이렇게 요청하면 | 이런 결과가 나온다 |
|-----------------|--------------------|
| "이 양식은 그대로 두고 내용만 서울불꽃축제 결과 보고서로 바꿔줘" | 같은 양식의 `…_결과보고.hwpx` + 바꾼 항목 표 |
| "이 결재문서로 운영 결과 보고서를 만들어줘. 기관명은 한강사업본부, 담당자는 김한강, 결재자는 박여의" | 결재선·기관명·본문이 바뀐 .hwpx |

실습 샘플: `practice-samples` 스킬로 `doc-hwpx-template` 세트를 복사해서 시험한다.

## 커스터마이즈 포인트

플러그인 설치 폴더를 고치지 말고 오버라이드 폴더에 파일을 둔다(`references/_shared/overrides.md`).
`<작업 폴더>/.claude/claude-skills/hwpx-editor/` 또는 `~/.claude/claude-skills/hwpx-editor/`

| 수준 | 대상 | 파일(스킬 폴더 기준 상대 경로) | 형식 | 예시 |
|:---:|------|-------------------------------|------|------|
| L0 | 기본 기관명 | `settings.yaml` → `default_org` | 문자열 | `default_org: 한강사업본부` |
| L0 | 기본 부서 | `settings.yaml` → `default_department` | 문자열 | `default_department: 총무과` |
| L1 | 기관 표준 양식 | `templates/<양식이름>.hwpx` | HWPX | `templates/결재문서.hwpx` |
| L2 | 용어집·직위 표기 규칙 | `references/glossary.md` | 마크다운 | "주무관 → 담당" 등 |

보호 규칙(오버라이드로 바뀌지 않음): 원본 덮어쓰기 금지, 비밀 정보 파일 기록 금지, 투자 권유 금지, 외부 전송 전 확인, 이상값 자동 수정 금지.
