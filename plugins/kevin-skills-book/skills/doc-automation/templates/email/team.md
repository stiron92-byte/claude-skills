# 팀 공유 이메일

## 구조

```
제목: [공유] {보고 주제} ({기간 또는 날짜})

팀원 여러분 안녕하세요,

{보고 주제} 내용을 공유합니다.

📌 요약
  {핵심 3줄}

📊 주요 내용
  - {숫자가 들어간 사실 1}
  - {사실 2}
  - {사실 3}
  - (필요하면 표 형태로 상위 5개)

✅ 액션 아이템
  1. {할 일} — {담당} / {기한}
  2. ...

❓ 확인이 필요한 점
  - {자료에 없거나 불확실한 것}

자세한 내용은 첨부한 {파일명}을 참고해 주세요.
```

## 쓰는 법

- 해요체 또는 회사 관례
- 액션 아이템은 담당·기한을 모르면 "미정"으로 쓴다(지어내지 않는다)
- 숫자는 PPT와 같은 값, 같은 출처
