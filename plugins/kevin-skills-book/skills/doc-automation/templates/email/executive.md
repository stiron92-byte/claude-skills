# 임원·상위 보고 이메일

## 구조

```
제목: [보고] {보고 주제} — {핵심 결론 한 구절}

{받는 분} 님께,

{보고 주제}를 보고드립니다.

■ 결론
  {대상이 알고 싶은 답 1~2문장}

■ 근거
  - {숫자가 들어간 근거 1}
  - {근거 2}
  - {근거 3}

■ 리스크·확인 필요
  - {결론을 바꿀 수 있는 요인}

■ 요청 사항
  - {결정·승인이 필요한 것, 기한}

상세 내용은 첨부한 보고서({파일명})를 참고해 주십시오.

{보낸 사람} 드림
```

## 쓰는 법

- 3분 안에 읽히는 분량(본문 15줄 이내)
- 결론을 맨 앞에. 배경 설명은 첨부 PPT로
- 숫자는 PPT와 같은 값, 같은 출처
- 하십시오체
- 요청 사항이 없으면 "참고용 보고입니다"로 끝맺는다
