# 음성 변환(STT) — 모델, 용어 사전, 긴 녹음, 대안

`scripts/transcribe.py`는 로컬 faster-whisper로 변환한다. 음성은 이 컴퓨터 밖으로 나가지 않는다(변환된 텍스트만 Claude가 읽는다).

## 1. 모델 고르기(--model auto가 하는 일)

| 모델 | 내려받기 | CPU 처리 시간(1분 음성당) | 쓰임 |
|------|---------:|--------------------------:|------|
| base | 145MB | 약 5초(실측, 샘플 3개 평균) | 영어 기본. 한국어는 고유명사·숫자 오인식이 잦다 |
| small | 465MB | 약 20초(추정) | 한국어 기본 |
| medium | 1.5GB | 약 55초(추정) | 정확도가 더 필요할 때 |
| large-v3-turbo | 1.6GB | 약 35초(추정) | GPU가 있거나 시간 여유가 있을 때 |

추정값은 실측이 아니다. 처음 실행할 때 출력되는 "예상 약 n분"도 이 표로 계산한다.

- 사용자 맞춤 `settings.yaml`의 `stt_model`이 있으면 그것을 쓴다.
- 고른 모델이 없고 디스크가 모자라면, 이미 받아 둔 모델 중 가장 큰 것으로 바꾸고 이유를 출력한다. 그 경우 전달할 때 "정확도가 낮은 모델로 변환했다"고 알린다.
- 처음 쓰는 모델은 내려받는 시간이 더 든다(인터넷 필요).

## 2. 용어 사전 — 교정 참고(기본)와 인식 힌트(선택)

참석자 이름, 제품명, 약어를 적은 파일을 `--glossary`로 주거나 오버라이드 폴더의 `references/glossary.md`에 둔다.

```markdown
# 참석자
- 김PM, 이개발, 박디자인, 정기획
# 용어
- 퍼블리싱, AWS SES, 이월, 스프린트
```

- 기본: 용어를 `transcript.json`의 `meta.glossary_terms`에 기록만 한다. 회의록 단계에서 오인식을 고칠 때 참고하고, 고친 내용은 `meta.corrections`에 선언한다.
- `--hotwords`: 용어를 인식 힌트로도 넘긴다. 이름 오인식은 크게 준다. 그러나 숫자가 망가질 수 있다.

실측(base 모델):

| 녹음 | 힌트 없음 | `--hotwords` |
|------|-----------|--------------|
| 스프린트 회의(이름 위주) | '김 피암·정기회·퍼글리싱·AWS ss' | 네 단어 모두 바르게 인식 |
| 기획 회의(숫자 위주) | '총 3억', 발언 54개 | '총 4월'(예산 소실), 발언이 21개로 뭉침 |

숫자·금액이 중요한 회의에는 `--hotwords`를 쓰지 않는다. 이름만 문제라면 힌트 없이 변환하고 회의록 단계에서 교정하는 편이 안전하다.

## 3. 결과 읽기

- `transcript.txt`: `T0012 [00:00:53] 텍스트`. 줄 끝 `(?)`는 STT가 확신하지 못한 발언이다(평균 로그 확률 −1 미만, 무음 확률 0.6 초과, 반복 의심).
- `transcript.json`: 같은 내용과 모델·언어·길이·확인 필요 수.
- 화자는 구분하지 않는다. 누가 말했는지는 내용("이개발님, 백엔드는요?" → 다음 발언)과 마무리 정리 발언으로 판단하고, 확실하지 않으면 회의록에 단정하지 않는다.

## 4. 긴 녹음

- 크기 제한은 없다. 1시간이 넘으면 시작할 때 예상 시간을 알리고, 발언을 받는 즉시 파일에 쓴다.
- 중간에 끊기면 같은 명령에 `--resume`을 붙인다. 마지막 발언 이후부터 이어서 변환한다.
- 명령 실행 시간 제한이 있는 환경(Cowork 등)에서는 30분 단위로 나눈 파일을 차례로 넣거나, 아래 대안을 쓴다.

## 5. 대안: 이미 텍스트가 있을 때

클로바노트·노션·Zoom·Teams가 만든 녹취(텍스트, SRT, VTT, 워드)는 `scripts/prepare_transcript.py`로 넣는다. 음성 변환보다 빠르고, 화자 이름이 이미 붙어 있어 정확하다.

## 6. 같은 녹음도 모델마다 숫자를 다르게 듣는다

샘플 기획 회의의 구독 가격 발언을 모델별로 변환한 결과다. 정답표는 다수 결과와 맥락으로 11,900원으로 정했다.

| 모델 | 제안 발언 | 결정 발언 |
|------|-----------|-----------|
| base | 월 1,900원 | 월 19,900원 |
| base + 힌트 | 월 만천九百원 | 월 1,900원 |
| small | 월 만천 구백 원 | 월 11900원 |
| small + 힌트 | 월 만천 구백 원 | 월 만천 구백 원 |
| medium | 월 11,900원 | 월 1,900원 |

'만'처럼 짧은 단위는 빠지기 쉽다. 금액·수량이 발언마다 다르면 하나를 골라 단정하지 말고 `uncertain`에 적어 확인을 요청한다.

## 7. 알려진 문제

- faster-whisper 1.2.1의 내장 디코더는 PyAV 15 이상에서 `metadata_errors` 인자 오류로 실패한다. transcribe.py는 PyAV로 직접 디코딩해 이 문제를 피한다(별도 ffmpeg 설치 불필요).
