# Content Repurpose Skill

원소스 멀티콘텐츠 자동 생성 스킬 - 하나의 원본 콘텐츠를 여러 플랫폼에 최적화된 콘텐츠로 변환합니다.

## 설치 방법

이 스킬 폴더를 프로젝트의 `.claude/skills/` 디렉토리에 복사합니다:

```bash
cp -r content-repurpose /path/to/project/.claude/skills/
```

## 사용법

### 콘텐츠 변환 (기본 모드)

원본 콘텐츠(유튜브 대본, 강의, 회의록, 블로그 글 등)를 전달하면 원하는 플랫폼에 맞게 자동 변환합니다.

사용 예:
- "이 유튜브 대본을 블로그와 인스타로 변환해줘"
- "이 강의 내용을 SNS 콘텐츠로 만들어줘"
- "콘텐츠 리퍼포징 해줘"

### 콘텐츠 감사 (audit)

기존 콘텐츠 라이브러리를 분석하여 부족한 주제, 중복, 개선 포인트를 도출합니다.

사용 예:
- "내 블로그 콘텐츠 감사해줘"
- "콘텐츠 audit 해줘"

### 갭 분석 (gap)

경쟁 채널/사이트 대비 콘텐츠 갭을 분석합니다.

사용 예:
- "경쟁 채널이랑 비교해서 콘텐츠 갭 분석해줘"
- "콘텐츠 gap 분석 해줘"

## 지원 플랫폼

| 플랫폼 | 특성 |
|--------|------|
| SEO 블로그 포스트 | 키워드 최적화, H2/H3 구조 |
| 네이버 블로그 | 네이버 검색 최적화, 친근한 구어체 |
| 브런치 글 | 에세이형, 깊이 있는 서술 |
| Medium 아티클 | 전문적 에세이형, 태그 최적화 |
| X (Twitter) 스레드 | 140자 분할, 훅-인사이트-CTA |
| LinkedIn 게시물 | 전문가 톤, 경험 공유형 |
| Instagram 캡션 | 감성적, 해시태그 30개 |
| Threads 게시물 | 캐주얼, 트렌디 |
| Facebook 게시물 | 커뮤니티형, 공유 유도 |
| 뉴스레터 본문 | 1:1 대화형, Substack/스티비 호환 |
| YouTube Shorts 스크립트 | 30~60초, 3초 훅 |
| TikTok 스크립트 | 숏폼, 에너지 넘치는 톤 |
| Pinterest 핀 설명 | 검색 최적화, 실용적 |
| 썸네일/비주얼 가이드 | 텍스트, 색상, 레이아웃 |

## 출력 언어

기본값은 한국어이며, 사용자 요청 시 다른 언어로도 생성 가능합니다.

## 파일 구조

```
content-repurpose/
├── SKILL.md              # 스킬 정의 (핵심 파일)
├── README.md             # 이 파일
└── examples/
    └── example-usage.md  # 사용 예시
```
