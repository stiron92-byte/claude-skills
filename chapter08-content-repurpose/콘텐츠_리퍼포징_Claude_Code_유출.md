2026년 3월 31일, 만우절 하루 전에 만우절 같은 일이 벌어졌다. Anthropic의 핵심 제품 Claude Code의 소스코드 50만 줄이 npm 배포 과정에서 통째로 유출된 것이다. TypeScript 기반의 소스맵이 함께 포함되면서 코드는 완벽하게 복구 가능한 상태였고, CI/CD 파이프라인에서 발생한 이 실수는 Anthropic에게 뼈아픈 대형 사고가 됐다.

### 2시간 만에 벌어진 일: Claw Code의 탄생

유출 직후 벌어진 일은 더 충격적이었다. 샌프란시스코에 있던 한국인 엔지니어 그룹이 유출된 코드를 기반으로 AI 모델을 활용해 Python과 Rust로 전체 코드베이스를 재작성했다. 소요 시간은 단 2시간. 이른바 '메타 하네스' 전문가들이 서브 에이전트를 대량으로 돌려 50만 줄의 코드를 완전히 포팅해낸 것이다.

Claw Code라 이름 붙여진 이 프로젝트는 GitHub에서 Kubernetes, Node.js, Go, Rust 같은 전설적인 오픈소스 프로젝트보다 더 많은 스타를 받았다. 포크만 10만 회를 넘겼다. 그런데 아이러니하게도 이 코드를 실제로 돌려본 사람은 거의 없었다. 사이오닉 고석현 대표는 당사자인 박진형(Sigrid Jin)에게 직접 물었을 때, 돌아온 답은 "이건 밈이다"였다고 전한다. 실제로 코드는 거의 동작하지 않는 개념도 수준의 것이었지만, 사람들은 코드의 품질이 아닌 이 사건의 '의미'에 스타를 눌렀다.

### Anthropic이 스스로 증명한 것: AI가 쓴 50만 줄의 실체

유출된 코드를 분석한 전문가들이 공통적으로 지적한 점이 있다. Anthropic이 공언했던 "우리 코드의 대부분은 AI로 작성된다"는 말이 사실이었다는 것이다. 코드의 human interpretability, 즉 사람이 읽고 유지보수하기 좋은 구조는 전혀 고려되지 않았다. 대신 모델이 짜기 좋고, 모델에 입력하기 좋은 형태로 최적화되어 있었다.

특히 주목할 점은 토큰 캐싱에 대한 집착적인 최적화였다. Claude Code의 핵심 경쟁력은 모델 성능 자체가 아니라 프롬프트를 정렬해서 캐시 히트율을 극대화하고, 내부 GPU 사용량을 줄이는 엔지니어링에 있었다. 실제로 Gemini나 Codex 같은 다른 모델을 붙여도 Claude Code의 하네스는 잘 동작했다는 점이 이를 뒷받침한다.

### 클린룸 논쟁: AI 재작성은 저작권 침해인가

Claw Code 팀은 "우리는 AI 모델을 사용해 다른 언어로 재구축했다"고 밝혔다. 전통적인 저작권법 기준으로 보면 동일한 코드 구문이 전혀 없다. 그런데 여기서 아이러니한 상황이 발생한다. Anthropic 스스로가 그동안 "AI로 재작성·해석된 것은 추론과 학습에 의한 것이므로 저작권 문제가 없다"고 주장해왔기 때문이다. 자사 코드에 대해서만 DMCA를 들이미는 것은 자가당착이라는 비판이 나왔고, 실제로 Anthropic은 AI로 리라이팅된 Claw Code에 대해서는 삭제 요청을 보내지 않았다.

고석현 대표는 이 상황을 이렇게 정리한다. "클린룸이냐 아니냐, 이게 정답이냐 아니냐보다 중요한 건 이 사건을 둘러싼 상황이 굉장히 입체적이라는 것이다."

### 소스코드 가치가 0에 수렴하는 시대

이 사건이 진짜로 던지는 질문은 따로 있다. 소스코드의 가치는 얼마인가? 노정석 대표는 이렇게 말한다. "PRD 몇 개만 있으면 그것조차도 지금 만들어지는 세상이다. 그게 가능한 이유는 모델이 슈퍼 인텔리전스이기 때문이다."

유튜브가 초창기 불법 영화 공유 사이트에서 시작해 세상을 바꿨듯, 이 사건도 법적 이슈로 남기보다는 새로운 시대의 전환점으로 묻힐 가능성이 높다. 모든 사람이 AI로 코드를 재작성할 수 있는 세상에서, 소스코드를 본 것과 작동하는 제품의 UX를 보고 복제하는 것의 차이는 점점 사라지고 있다.

### 하네스 엔지니어링이 새로운 핵심이다

결국 남는 것은 코드가 아니라 하네스다. 모델을 semantic CPU로, 하네스를 운영 체제로 보는 패러다임이 자리잡고 있다. Claude Code 유출 사건은 역설적으로 코드 자체보다 "코드를 어떻게 조합하고 최적화하는가"가 핵심 경쟁력임을 증명했다. 토큰 효율화, 컨텍스트 관리, 에이전트 제어 — 이런 하네스 레이어의 설계가 AI 시대의 진짜 IP가 되고 있다.

2028년 슈퍼 인텔리전스가 모든 일을 처리하는 세상에서 돌아보면, 이 사건은 너무 당연한 일이 될 것이다. 지금 우리는 과거의 시각으로 현재를 해석하고 있는 것일 수도 있다.
