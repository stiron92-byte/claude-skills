# MarketingSkills 레포 분석 & 한국 시장 커스터마이징 로드맵

## 1. 저장소 개요

**marketingskills**는 Corey Haines가 만든 AI 에이전트용 마케팅 스킬 컬렉션으로, SaaS/소프트웨어 제품의 마케팅 업무를 자동화합니다. Claude Code, Cursor, Windsurf 등 다양한 에이전트에서 동작하며, MIT 라이선스로 자유롭게 수정 가능합니다.

**핵심 구조:**
- `product-marketing-context` 스킬이 모든 스킬의 기반 (제품/고객/포지셔닝 정보)
- 34개 스킬이 7개 카테고리로 구성
- 스킬 간 상호 참조 체계 (예: copywriting ↔ page-cro ↔ ab-test-setup)
- `tools/` 디렉토리에 51개 CLI 도구 + API 통합 가이드 포함

## 3. 한국 시장 적합성 평가

### 평가 기준

각 스킬을 아래 5가지 기준으로 평가합니다 (각 1-5점):

- **즉시 활용도**: 한국 시장에서 수정 없이 바로 사용 가능한 정도
- **커스터마이징 필요도**: 한국화가 필요한 정도 (높을수록 많이 수정 필요)
- **한국 시장 중요도**: 한국 마케팅 실무에서의 중요성
- **플랫폼 차이**: 한국 vs 미국 플랫폼 생태계 차이 정도
- **문화적 차이**: 한국 소비자 행동/문화와의 괴리 정도

## 4. 커스터마이징 로드맵

### Phase 1: 기반 작업 (1주차)

**목표:** 한국 시장 컨텍스트 기반 구축

1. **product-marketing-context 한국화**
   - 한국 시장 전용 섹션 추가 (한국 경쟁 환경, 한국 고객 특성, 한국 채널 맵)
   - 한국어 고객 언어(Voice of Customer) 수집 가이드
   - 한국 주요 리뷰 플랫폼 목록 (네이버 카페, 블라인드, 잡플래닛 등)

2. **한국 플랫폼 레지스트리 작성**
   - 광고: 네이버 검색광고, 카카오모먼트, 당근비즈프로필, 토스 광고
   - 소셜: 카카오톡 채널, 네이버 블로그, 인스타그램, 유튜브
   - 분석: 네이버 애널리틱스, 카카오 픽셀, 에이스카운터
   - 결제: 토스페이먼츠, NHN KCP, 이니시스, 카카오페이
   - 메시징: 카카오 알림톡/친구톡, NHN Cloud 문자

### Phase 2: 최우선 스킬 한국화 (2-3주차)

**7개 최우선 스킬을 한국 실무에 맞게 전면 개편:**

1. **paid-ads-kr**: 네이버 SA/DA, 카카오모먼트, 당근, GFA(구글) 위주로 재구성
2. **social-content-kr**: 카카오톡/네이버 블로그/인스타/유튜브 4대 채널 중심
3. **seo-audit-kr**: 네이버 SEO + 구글 SEO 이중 감사 체계
4. **cold-outreach-kr**: 이메일 + 카카오비즈메시지 + 전화 통합 아웃리치
5. **content-strategy-kr**: 네이버/유튜브/커뮤니티 콘텐츠 전략
6. **copywriting-kr**: 한국어 카피라이팅 원칙, 톤앤매너 가이드
7. **email-sequence-kr**: 이메일 + 카카오톡 옴니채널 시퀀스

### Phase 3: 높은 우선순위 스킬 (4-5주차)

**9개 스킬 부분 수정:**

- ad-creative에 한국 광고 스펙/카피 추가
- analytics-tracking에 네이버/카카오 트래킹 코드 추가
- pricing-strategy에 한국 SaaS 가격 벤치마크 추가
- launch-strategy에 한국 런칭 채널 추가
- customer-research에 한국 리서치 소스 추가
- competitor-alternatives에 한국 경쟁 분석 소스 추가
- page-cro에 한국 결제/인증 패턴 추가
- signup-flow-cro에 한국 인증 수단 추가
- referral-program에 카카오톡 공유 메커니즘 추가

### Phase 4: 한국 전용 신규 스킬 (6-7주차)

**한국 시장에만 있는 마케팅 영역용 신규 스킬:**

1. **naver-marketing**: 네이버 블로그 마케팅, 스마트스토어 SEO, 네이버 플레이스 최적화
2. **kakao-channel**: 카카오톡 채널 운영, 알림톡/친구톡 전략, 카카오 커머스
3. **korean-community**: 한국 커뮤니티(에펨코리아, 디시인사이드, 클리앙, 네이버 카페) 마케팅
4. **korean-influencer**: 한국 인플루언서 마케팅 (유튜브 크리에이터, 인스타 인플루언서, 블로그 체험단)
5. **korean-commerce**: 쿠팡, 네이버 스마트스토어 등 한국 이커머스 마케팅

### Phase 5: 검증 및 최적화 (8주차)

- 각 스킬 실무 테스트 (실제 마케팅 시나리오 적용)
- 한국 마케터 피드백 수집 및 반영
- 스킬 간 상호 참조 업데이트
- 버전 관리 및 문서화

## 5. 핵심 커스터마이징 영역 상세

### 5-1. 플랫폼 생태계 차이

| 영역 | 미국 (원본) | 한국 (커스터마이징) |
|------|-----------|-----------------|
| 검색 | Google 90%+ | 네이버 ~55%, Google ~35%, 다음 ~5% |
| SNS | Twitter/X, LinkedIn, Facebook | 카카오톡, 인스타그램, 유튜브, 네이버 블로그 |
| 이커머스 | Shopify, Amazon | 쿠팡, 네이버 스마트스토어, 11번가 |
| 결제 | Stripe, PayPal | 토스페이먼츠, KCP, 이니시스, 카카오페이 |
| CRM | HubSpot, Salesforce | 채널톡, 세일즈맵, HubSpot(일부) |
| 메시징 | Email | 카카오 알림톡/친구톡, LMS/MMS |
| 리뷰 | G2, Capterra | 네이버 카페, 블라인드, 잡플래닛 |
| 커뮤니티 | Reddit, HN, Product Hunt | 디시, 에펨, 클리앙, 디스콰이엇 |
| 인증 | Google, Apple SSO | 카카오, 네이버, PASS 본인인증 |

### 5-2. 한국어 카피라이팅 고려사항

- 존댓말(-습니다체) vs 해요체 vs 반말(-해) 톤 전략
- 한국어 특성: 조사 변화, 띄어쓰기, 숫자 표기(만/억 단위)
- 한국 소비자가 반응하는 카피 패턴: 혜택 강조, 한정/마감, 사회적 증거
- 한국식 CTA: "지금 시작하기", "무료로 체험하기", "상담 신청하기"
- B2B 한국어 톤: 격식체 우선, 전문용어와 한글 병기

### 5-3. 한국 개인정보보호 규제

- 개인정보보호법(PIPA) 기반 동의 수집 요건
- 쿠키 동의 팝업 대신 개인정보 수집·이용 동의 체크박스
- 마케팅 수신 동의 별도 필수 (이메일, SMS, 카카오톡 각각)
- 14세 미만 법정대리인 동의 필요
- 정보통신망법 기반 광고성 메시지 발송 규제
